
# Competitor Intelligence Dashboard

A comprehensive analytical dashboard for enterprise sales teams to research competitor relationships with target companies. This tool helps sales teams understand the competitive landscape before making their pitch.

![Dashboard Preview](/placeholder.svg?height=400&width=800&query=enterprise%20dashboard%20with%20charts%20and%20analytics)

## Overview

This dashboard provides a data-driven view of competitor relationships, including:

- Market share analysis
- Relationship strength metrics
- Project timeline visualization
- Comprehensive competitor comparison
- Detailed project information

## Features

- **Interactive Filtering**: Filter by competitor, project type, and date range
- **Key Performance Metrics**: View active relationships, total projects, contract values, and more
- **Visual Analytics**: Multiple chart types for data visualization
- **Detailed Competitor Insights**: Comprehensive view of competitor relationships
- **Responsive Design**: Works on desktop and mobile devices

## Technology Stack

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS
- shadcn/ui components
- Chart.js for data visualization
- date-fns for date handling

## Prerequisites

- Node.js 18.x or higher
- npm or yarn
